# What Does ChatGPT Consider a Beautiful Woman?

This collection has two rounds: the first has no nationality restriction; the second includes Chinese women. Candidates were obtained at random, grouped by the model's subjective impressions, and then 10 photos were randomly selected from each group.

The two rounds contain 40 photos in total: 20 labeled "beautiful" and 20 labeled "average-looking." The four groups are shown below.

## Experiment Environment

- Experiment date: October 6, 2026, Beijing time (Asia/Shanghai, UTC+8).
- Model: GPT-6.1 Sol (`gpt-6.1-sol`), reasoning effort `xhigh`.
- Client: Codex desktop app (Windows), version `26.930.41038`, build `13022`.
- ChatGPT client version: not applicable. This experiment was conducted through the Codex desktop app, not a separate ChatGPT client.
